# 💍 אישורי הגעה לחתונה

- `index.html` הוא דף אישור ההגעה שהאורחים רואים. הוא מתארח ב־GitHub Pages.
- `apps-script/Code.gs` הוא צד השרת. הוא רץ בתוך Google Sheets ושומר שם את התשובות.

## התקנה (פעם אחת, בערך 15 דקות)

### 1. הגיליון ו־Apps Script
1. פותחים Google Sheet חדש, למשל בשם "אישורי הגעה".
2. בתפריט: **Extensions → Apps Script**. מוחקים את מה שיש שם ומדביקים את כל התוכן של `apps-script/Code.gs`. שומרים.
3. חוזרים לגיליון ומרעננים את הדף. יופיע תפריט **💍 אישורי הגעה**. בוחרים בו **הגדרה ראשונית** ומאשרים את ההרשאות שגוגל מבקש.
   - אם מופיעה האזהרה "Google hasn't verified this app", לוחצים Advanced ואז Go to ... . זה הסקריפט שלך.
4. בעורך Apps Script: **Deploy → New deployment → סוג Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - לוחצים Deploy ומעתיקים את ה־URL שנגמר ב־`/exec`.

### 2. האתר
1. יוצרים ריפו ב־GitHub, למשל `wedding-rsvp`, ומעלים אליו את `index.html` ואת `invite.jpg`.
2. ב־`index.html`:
   - בתוך `CONFIG`, מדביקים ב־`API_URL` את הכתובת מסעיף 1.4.
   - בתגית `og:image` למעלה מחליפים את `USERNAME` בשם המשתמש שלך ב־GitHub. זו התמונה שוואטסאפ מציג מעל הקישור.
3. בריפו: **Settings → Pages → Deploy from branch → main / root**. אחרי דקה האתר יהיה זמין בכתובת `https://<user>.github.io/wedding-rsvp/`.

### 3. חיבור הקישורים
1. ב־`Code.gs` מעדכנים את `SITE_URL` לכתובת האתר, ואת `INVITE_MESSAGE` לנוסח ההודעה.
2. **חשוב:** אחרי כל שינוי ב־Code.gs צריך לעשות **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**. אחרת השינוי לא ייכנס לתוקף. הכתובת נשארת אותה כתובת.

## שימוש

1. בגיליון **מוזמנים** ממלאים **שם**, **טלפון** ו־**מקסימום אורחים** (ריק = 2).
   - בשם אפשר לכתוב למשל "משפחת כהן" או "דנה ויוסי".
   - הטלפון יכול להיות בכל פורמט: `050-1234567`, `+972...` וכו'.
2. בתפריט: **💍 אישורי הגעה → צור קישורי שליחה**.
3. בעמודה **שליחה** לוחצים על "שלח בוואטסאפ 📲". וואטסאפ נפתח עם ההודעה מוכנה, ולוחצים שלח. אחרי כל שליחה מסמנים ✓ בעמודה **נשלח**.
4. התשובות נכנסות לגיליון מיד. בגיליון **סיכום** רואים כמה אישרו, כמה מנות מיוחדות צריך ואת רשימת האלרגיות.

> אפשר להוסיף מוזמנים בכל שלב ולהריץ שוב "צור קישורי שליחה". מזהים קיימים לא משתנים, כך שקישורים שכבר נשלחו ממשיכים לעבוד.
